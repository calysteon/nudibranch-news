# Images

Drop the following image files into this folder. The site references them by these exact names:

| Filename | What it is |
| --- | --- |
| `leopard-dorid-logo.png` | The hand-drawn Leopard Dorid illustration. Used as the site logo / favicon. A transparent (or white) background works best. |
| `armina-golden-gardens-1.jpg` | First photo of the Striped Nudibranch washed up at Golden Gardens. |
| `armina-golden-gardens-2.jpg` | Second photo of the Striped Nudibranch washed up at Golden Gardens. |

Once these three files are in place, the homepage and the first article will display correctly.
